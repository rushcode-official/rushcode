# RushCode

**RushCode** — AI-генератор кода для разработчиков. Помогает писать, рефакторить и объяснять код прямо в редакторе.

> ™ RushCode. Все права защищены.

---

## 📌 О проекте

RushCode — это инструмент, который работает с вашим проектом и генерирует код на основе запросов на естественном языке. Аналог Cursor и подобных AI-ассистентов, ориентированный на скорость, русскоязычных разработчиков, работу с большими проектами.

**Статус:** активная разработка.

## 🚀 Возможности

- Генерация кода по текстовому описанию
- Работа с существующим проектом (чтение, изменение, объяснение)
- Языки / фреймворки — да, широкий охват: TS/JS, Python, Go, Rust, Swift, Kotlin, Java, C#, C/C++, PHP, Ruby, SQL и т.д. В этом репозитории работаю с TypeScript, SolidJS, Effect, Bun, Drizzle.
- Другие функции — поиск по репозиторию, рефакторинг, отладка, тесты и typecheck, git-коммиты, миграции и codegen, ревью, скрипты и CI.
