# RushCode

**RushCode** — AI-генератор кода для разработчиков. Помогает писать, рефакторить и объяснять код прямо в редакторе.

> ™ RushCode. Все права защищены.

---

## 📌 О проекте

RushCode — это инструмент, который работает с вашим проектом и генерирует код на основе запросов на естественном языке. Аналог Cursor и подобных AI-ассистентов, ориентированный на [кратко: скорость, русскоязычных разработчиков, работу с большими проектами и т.д.].

**Статус:** активная разработка.
